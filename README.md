
# 📘 Schoolzy Project  

Schoolzy is a School Management System with a public website and an admin dashboard.  
The **frontend design** is based on the TeknoLab HTML Template, while the **backend** and **dashboard** were fully developed using **ASP.NET Core 8** and **Blazor**.  

---

## 🌐 Main Website Features
- Home Page  
- About Page (Dynamic: Location, Contact Info, Social Links, Team Members, Clients)  
- Contact Us Page (Form integrated with **SMTP Email Service** + saved to database)  
- Modules & Pricing Page (Dynamic Packages from database)  

---

## 🖥️ Dashboard Features
- Separate Admin Login  
- Manage Company Data (Location, Phone, Email, Social Links)  
- Manage Clients  
- Manage Packages  
- Manage Team Members  
- View submitted contact forms  

---

## ⚙️ Technical Notes
- **Backend:** ASP.NET Core 8  
- **Frontend:** HTML, Bootstrap, Blazor  
- **Database:** SQL Server  
- **Email Service:** SMTP  
- **Responsive:** Yes, mobile-friendly
